# Module 1 — Welcome

Welcome.

In this video, we will build a complete certificate-based IPsec connection between a Semtech AirLink router and a Palo Alto Networks Next-Generation Firewall.

The video is intended as a practical self-training resource for network and security engineers. It may also be used as a public technical reference.

Rather than showing configuration steps without context, we will also explain why each component is required and how the individual technologies work together.

Throughout the video, we will work with the actual management interfaces of the products involved, including CyberArk Certificate Manager, the Semtech AirLink management interface, and PAN-OS.

Product interfaces evolve over time. Individual screens may therefore differ from those shown here. The underlying engineering principles and the overall configuration process remain the same.

We will build the connection from start to finish as one continuous technical process.

At each major stage, we will configure the required components, verify the result, and then continue with the next dependency until the secure connection is complete.

By the end of this video, you should understand how the solution operates, how to reproduce the configuration, and where to begin troubleshooting if something does not behave as expected.

Let us begin.
